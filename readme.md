
# 🐱 MeowMood

### A Meme for Every Mood 😸

MeowMood is an interactive cat meme picker built using HTML, CSS, and JavaScript. Select your current emotion and get a matching cat meme or GIF.

## ✨ Features

- 😸 Emotion-based meme selection
- 🎞️ GIF-only filtering
- 🔍 Search emotions
- 🗂️ Category filtering
- 🎲 Random meme generator
- ❤️ Save favorite memes
- 💾 Persistent favorites using Local Storage
- ⬇️ Download memes
- 🌙 Dark mode with saved theme preference
- 📱 Responsive design

## 🚀 My Extensions

After completing the original learning project, I extended it with:

- 🔍 Emotion search functionality
- 🗂️ Animals, Coding, Funny, and Reaction categories
- 💻 Additional coding and reaction meme data
- 🎲 Random meme generator
- ❤️ Favorites system
- 💾 Local Storage for persistent favorites
- ⬇️ Meme download functionality
- 🌙 Persistent dark mode
- 🎨 Completely redesigned UI
- 📱 Improved responsive layout
